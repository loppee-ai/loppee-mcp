# Security

Please do not report suspected vulnerabilities through a public GitHub issue.

Use GitHub's private vulnerability reporting form:
https://github.com/loppee-ai/loppee-mcp/security/advisories/new

If that form is unavailable, use the Loppee support channel at
https://loppee.com/support. Include enough detail for the team to reproduce the
problem without sharing customer data, credentials, access tokens, private
keys, precise locations, or other secrets.

This repository contains public metadata and documentation only. Security
reports concerning the live service remain subject to Loppee's published terms
and privacy policy.
